# Page structure

- **Authentication:** centered form card, inline validation, one primary action, and links to the related recovery or registration flow.
- **Dashboard:** persistent group navigation, group switcher, balance summary, collection chart, open loans, and recent contributions.
- **Lists:** group selector, search control, semantic data table, and a contextual create action.
- **Create forms:** labeled fields, inline validation, a pending submit state, and a confirmation only after the API succeeds.
- **Reports:** financial or member table with the reporting group named above the data.

This document describes the implemented information layout rather than a pixel-perfect mockup.
