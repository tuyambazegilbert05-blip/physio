# Design system

Use white paper-like surfaces, slate text, indigo as the primary action color, green for confirmed positive state, amber for review, and red for errors. Keep financial amounts visually prominent and always pair color with a text label. Components live in `src/components/`; feature-specific components stay with their domain.

Shared motion values are in `src/styles/variables.css`. Follow [the motion system](../architecture/motion-system.md) for animation technology, timing, reduced motion, and financial-state rules.
