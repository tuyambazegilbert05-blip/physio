# UI guidelines

- Label every field and connect inline errors with its control.
- Keep navigation reachable by keyboard and expose current state with text or ARIA state.
- Use semantic headings, tables, status labels, and focus-visible styles.
- Do not display example financial values as if they came from a group account.
- Show errors near the action that failed and allow retry where safe.
- Honor `prefers-reduced-motion` and keep charts supplementary to their tabular values.
